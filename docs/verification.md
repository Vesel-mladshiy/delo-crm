| --- | --- |
| TypeScript, `npm run typecheck` | Пройдено |
| Модульные тесты, `npm test` | 7 из 7 |
| Сборка Vinext / Vite | Пройдено |
| Реальная локальная D1 и API | 37 HTTP-проверок пройдено |
| Playwright desktop, 1440×1000 | Пройдено |
| Playwright mobile, 390×844 | Пройдено, нет горизонтального переполнения страницы |
| Перетаскивание сделки и сохранение этапа | Пройдено |
| Сохранение после перезагрузки | Пройдено |
| Выполнение задачи | Пройдено |
| Поиск, экспорт CSV, карточки и формы | Пройдено |
| Изоляция двух песочниц, запрет чужого клиента / сделки | Пройдено |
| Заметки с HTML / script выводятся как текст | Пройдено |
| Локальный mock входа с ChatGPT, запрет сброса личного пространства | Пройдено |
| Необработанные ошибки JavaScript в проверенном браузерном сценарии | Не обнаружены |

Авторизация ChatGPT в production требует реального интерактивного входа владельца; локальная имитация не заменяет эту проверку. Сценарии нагрузки, независимый аудит безопасности, Safari и реальные мобильные устройства не проверялись. CI подготовлен, но его выполнение на GitHub требует публикации репозитория.

Воспроизводимые команды и ограничения — в README. Тесты, изменяющие данные, ограничены локальным адресом.
