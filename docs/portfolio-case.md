# Дело CRM — описание для портфолио

**Задача:** дать небольшой сервисной компании единое место для клиентских контактов, воронки продаж и ближайших действий.

**Результат:** fullstack MVP с авторизацией, изолированной SQL-базой по владельцу, личной демопесочницей, CRUD клиентов и сделок, канбаном, задачами, поиском, экспортом и аналитикой. Интерфейс адаптирован для телефона.

**Стек:** React, TypeScript, Vinext / Vite, Cloudflare Workers и D1, Drizzle, Zod, Recharts, Radix UI, Playwright.

**Инженерные решения:** серверная проверка владения на каждой операции; same-origin проверка изменений; атомарная запись изменений и событий; SQL-миграции; отсутствие общего публичного демопароля; единые правила дат и расчёта выручки; проверки доступа между двумя независимыми сессиями.

**Разработка с AI:** реализация и проверки подготовлены с Codex. Конкретный личный вклад автора нужно дополнить после самостоятельной проверки из `ai-workflow.md`.
