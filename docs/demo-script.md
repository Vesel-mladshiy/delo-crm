# Демонстрация: 60–90 секунд

Запись экрана без озвучки создаётся `npm run demo:record`, результат — `outputs/delo-crm-demo.mp4`. Используется отдельная локальная демосессия. Подписи добавляются только в запись; исходный интерфейс приложения от этого не меняется.

| Время | Экран и действие | Возможный текст озвучки |
| --- | --- | --- |
| 0–8 c | Вход и кнопка демо | «Дело — небольшая CRM для студии или сервисного бизнеса. Открыть демо можно без регистрации». |
| 8–19 c | Обзор, показатели и график | «Здесь видны выручка, сделки в работе, конверсия и ближайшие задачи. Цифры считаются по данным из базы». |
| 19–31 c | Клиенты, поиск и карточка | «В карточке клиента собраны контакты, заметки и связанные сделки. Нужную компанию легко найти». |
| 31–48 c | Создание сделки | «Создаю сделку, выбираю клиента, указываю сумму и следующий шаг. Всё сохраняется через серверный API». |
| 48–60 c | Канбан и смена этапа | «Сделку можно перенести между этапами или изменить в карточке. После закрытия результат попадает в аналитику». |
| 60–69 c | Выполнение задачи | «Задачи помогают не забыть следующий шаг. Выполненное остаётся в истории». |
| 69–79 c | Аналитика | «Выручка, источники продаж и план на месяц помогают понять, как идёт бизнес. У каждого посетителя своя демоверсия». |

После записи проверьте длительность, читаемость и отсутствие персональных данных. При озвучке говорите о реально работающих возможностях; технические детали оставьте для README и собеседования.
